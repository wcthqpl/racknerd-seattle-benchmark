## 西雅图机房实测：配置、磁盘和 CPU 到底什么水平

目前能查到的两份独立实测（2025 年 11 月的 Black Friday 套餐测试和 2026 年 3 月更新的节点测评）指向的硬件是同一套：Intel Xeon E5-2680v2（10 核 20 线程，基础 2.8GHz），KVM 虚拟化，SSD RAID-10，1Gbps 带宽，上游为 HostPapa，ASN 是 AS36352。测试机已默认开启 BBR，但不支持 IPv6——这点和洛杉矶 DC02/DC03 不一样，后者可以开工单申请免费 IPv6。

磁盘表现两份测试略有出入：一份 fio 4K 读写各约 84 MB/s、IOPS 约 2.1 万；另一份测得 4K 读写约 64 MB/s、IOPS 约 1.6 万，整体 I/O 在 300MB/s 上下。对一块装在年付二十美元以内 VPS 上的 RAID-10 阵列来说，这个成绩属于正常偏好。

CPU 就是弱项了。Geekbench 5 单核 478、多核 857，Geekbench 6 单核 462、多核 1203，两份测试的结论一致：E5 平台性能中等，跑建站、代理、轻量服务没问题，但别指望它对标 RackNerd 自己的 AMD Ryzen 7950X 系列（DDR5 + NVMe Gen4，磁盘 I/O 超 1GB/s）。在意单核性能的话，西雅图的 Intel 款会让人失望。

**西雅图机房支持 Windows 吗？** 西雅图测评对应的是 KVM Linux VPS 产品线；Windows VPS 是独立产品线（AMD Ryzen 3900X + NVMe），有终身 7 折码 WIN-30OFF，但机房可选范围以结算页显示为准。
